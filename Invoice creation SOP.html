从 ASN 创建 Invoice
标准操作 SOP

记录从 Payment-Invoice 入口创建发票的完整操作：进入 Create Invoice，筛选并勾选待开票 ASN，确认开票信息后勾选必选项并提交。

操作路径 Payment-Invoice › Invoice › Create Invoice
Overview

流程总览

流程目标为已到货或需结算的 ASN 创建 Invoice
前置条件已确定需要开票的 ASN，并已准备好发票编号
完成标志提交后发票创建成功，页面返回 Invoice 列表
关键要素开票时间、发票编号、货物送达时间、两个必选项
1 进入创建入口 进入 Invoice 界面，选择 Create invoice。
›
2 筛选并勾选 ASN 使用 Vendor Code 及三个单据条件筛选，勾选待开票 ASN。
›
3 确认信息并提交 填写时间与发票编号，勾选两个必选项后 Submit。
1
进入入口

Payment-Invoice → Create Invoice

Operation: enter the Invoice screen, then select Create invoice
  • 进入 Payment-Invoice 模块。
  • 在左侧或功能区内进入 Invoice 界面。
  • 点击 Create invoice，进入创建发票页面。
2
选择开票对象

筛选并勾选要创建发票的 ASN

Operation: select the ASN(s) for which an invoice will be created
  • 在 Vendor Code 处选择供应商，可同时筛选不同的 Vendor Codes。
  • 结合下方三个条件进一步缩小范围，快速定位目标 ASN。
Shipped date range · 发货日期区间 Purchase order number(s) · PO 单号 ASN number · ASN 单号
  • 核对筛选结果后，勾选需要创建发票的 ASN。
  • 如涉及多个供应商或多张单据，建议逐项核对后再统一勾选，避免误选或漏选。
3
填写与提交

确认发票信息：开票时间、发票编号及货物送达时间

Operation: fill in the invoice details, check the two required items, then submit
  • 按实际情况选择正确的 开票时间 与 货物送达时间。
  • 在对应栏位填写 发票编号，确保编号与供应商发票一致且不重复。
  • 滚动到页面最下方，勾选两个必选项。
  • 再次核对后点击 Submit 提交。
注意：

两个必选项均需勾选后方可提交；请勿在未核对时间、发票编号或送达时间的情况下直接提交。

Pre-submit checklist

提交前核对清单

提交前按下表逐项确认，避免因筛选遗漏或信息填写错误而返工。

✓已勾选的 ASN 是本次需要开票的全部单据
✓开票时间与实际业务日期一致
✓货物送达时间已正确填写
✓发票编号已填入且与供应商发票一致
✓页面最下方两个必选项均已勾选
✓点击 Submit 后已确认创建成功
Glossary

名词说明

Payment-Invoice
系统内处理付款与发票业务的功能模块。
Create Invoice
创建发票的功能入口。
ASN
Advanced Shipping Notice，发货通知单，作为本次创建发票的业务对象。
Vendor Code
供应商代码，用于筛选不同供应商的发货单据。
Shipped date range
发货日期区间，可按发货日期筛选 ASN。
Purchase order number(s)
采购订单编号，可按 PO 单号筛选 ASN。
ASN number
ASN 单号，可直接定位指定发货通知。
